# Engineering

Skills for code work.

- **[typescript-expert](./typescript-expert/SKILL.md)** — Enforces senior-level strict TypeScript practices across the full stack: no `any`, branded ID types, Zod-based runtime validation with inferred types, explicit return types, discriminated-union error handling, and DRY utility types.
- **[dev-task](./dev-task/SKILL.md)** — Develop a GitHub issue end-to-end: gather requirements (interviewing if thin), plan a breakdown into sub-issues, get one approval, implement directly in the repo's working tree, run code review, and open a PR that moves the issue to Review on the linked GitHub Project.
- **[write-issue](./write-issue/SKILL.md)** — Write well-structured GitHub issues (Epic/Story/Task/Bug) from a loose idea or bug report, following the repo's issue templates, labels, and sub-issue hierarchy. Drafts first, creates after approval; no implementation.
- **[security-auditor](./security-auditor/SKILL.md)** — Runs structured npm security audits with actionable remediation plans: parses `npm audit --json`, classifies by severity, extracts CVEs, generates markdown reports, and supports risk acceptance via `security-exceptions.json`.
